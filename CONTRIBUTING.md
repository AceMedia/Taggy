# Contributing to Taggy

I welcome public issues with a clear reproduction, WordPress and PHP versions, and fictional example content. Please remove credentials, customer details and private URLs from logs and screenshots.

Code contributions to official releases are by invitation. Discuss a proposed change in an issue first; Ace Media reviews and publishes releases. This participation policy does not limit anyone's rights under the GPL licence to use, modify, fork or redistribute the plugin.

Keep changes focused and preserve existing settings, saved tags and supported WordPress versions. Include a regression test or a reproducible verification procedure. Use British English for documentation and interface copy.

Report vulnerabilities privately through [SECURITY.md](SECURITY.md), not a public issue.
