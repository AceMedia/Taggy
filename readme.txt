Provides WordPress tag suggestions for Movies via OMDb.

== Description ==

Taggy is a WordPress plugin that provides tag suggestions for movies via the OMDb API. This plugin enhances the tag input field in the WordPress post editor by suggesting movie titles based on the user's input.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`, or install the zip from Plugins > Add New.
2. Activate it through the Plugins screen.
3. Configure it from the plugin's settings screen where one exists.
