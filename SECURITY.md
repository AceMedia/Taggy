# Security policy

Please report a suspected Taggy vulnerability privately using GitHub's private vulnerability reporting form on this repository's **Security** tab if available, or email [shane@acemedia.ninja](mailto:shane@acemedia.ninja). Do not publish exploit details, API keys or customer data in an issue.

Include the affected version, WordPress and PHP versions, required privileges, impact, and a small reproduction using fictional content. Test only systems you own or have permission to assess. The latest official release is the supported line for security fixes; no backport or fixed response time is promised.
